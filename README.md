# Disease Checker (Python)

A simple school project. It asks yes/no questions about symptoms and
suggests a possible common illness with self-care tips (no medicine).

**Not medical advice.** See a doctor if you feel unwell.

## How to run
1. Install Python 3.
2. Run: python checker.py

## How it works
- input() asks the questions.
- if / elif / else picks a message.
